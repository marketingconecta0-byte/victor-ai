# Victor AI

Protótipo inicial de interface web responsiva para o assistente pessoal Victor AI.

## Estado atual
- Interface adaptada para celular e computador.
- Caixa de conversa e sugestões iniciais.
- **Ainda não conectado a um modelo de inteligência artificial**; as respostas atuais avisam que a configuração está em andamento.
- Nenhuma chave de API ou segredo deve ser colocado neste repositório.

## Próximas etapas
1. Publicar a interface com HTTPS para abrir no Android.
2. Escolher e conectar uma opção de IA sem custo inicial, considerando os limites do plano gratuito.
3. Adicionar instalação como atalho/PWA e, depois, integração com Telegram.

## Publicação
Pode ser publicado como site estático. Não coloque tokens do Telegram nem chaves privadas no código do navegador.
